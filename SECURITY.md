# Security

This is a local command-line tool. It does not serve HTTP or accept remote uploads. Checkpoints may execute Python during deserialization: use trusted, authorized files only. Run with your normal user permissions and keep outputs in directories you control. The output lock coordinates this CLI's writers; it cannot coordinate unrelated programs.

Do not post credentials, private scripts, voice recordings or exploitable details in public issues. If enabled on the published repository, use GitHub's private vulnerability reporting under Security → Report a vulnerability. Otherwise ask the maintainer for a private reporting channel without including the exploit. No response-time or supported-version SLA is established yet.

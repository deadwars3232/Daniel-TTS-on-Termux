usage: daniel_cli.py [-h] [--text EXPLICIT_TEXT] [--text-file TEXT_FILE]
                     [--batch BATCH] [--input-wav INPUT_WAV] [--output OUTPUT]
                     [--voice VOICE] [--checkpoint CHECKPOINT]
                     [--hubert-dir HUBERT_DIR] [--rmvpe-dir RMVPE_DIR]
                     [--voice-dir VOICE_DIR] [--threads {1,2,3,4}]
                     [--timeout TIMEOUT] [--overwrite] [--quiet | --verbose]
                     [--json] [--version]
                     [text] [destination]

Offline Termux narration CLI. No model imports until preflight succeeds.

positional arguments:
  text
  destination

options:
  -h, --help            show this help message and exit
  --text EXPLICIT_TEXT
  --text-file TEXT_FILE
  --batch BATCH         UTF-8 file: one utterance per nonempty line, joined
                        into one WAV
  --input-wav INPUT_WAV
                        convert an existing WAV, bypassing Piper
  --output OUTPUT
  --voice VOICE
  --checkpoint CHECKPOINT
  --hubert-dir HUBERT_DIR
  --rmvpe-dir RMVPE_DIR
  --voice-dir VOICE_DIR
  --threads {1,2,3,4}
  --timeout TIMEOUT     whole invocation deadline in seconds; 0 disables
  --overwrite
  --quiet
  --verbose
  --json
  --version             show program's version number and exit
